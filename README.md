# EventAccess V3 — GitHub Pages

Static academic simulation of accessible event navigation and issue management.

## Publish
1. Create a public GitHub repository (e.g. `eventaccess-v3`).
2. Upload the contents of this ZIP **to the repository root** (not the enclosing folder). Commit changes.
3. Open **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
4. Open `https://YOUR-USERNAME.github.io/eventaccess-v3/` after deployment.

## Important
The system is a simulated academic prototype, not real venue routing. Report and role data are stored in the browser's localStorage; different devices do not share data. QR access is simulated and does not provide real indoor positioning. Do not use the routes for safety-critical decisions.

The website uses only local relative file paths, so it works under a GitHub Pages repository subpath.
